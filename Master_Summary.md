#### 2. **Research Onion Framework (Saunders et al.)**

**Files:**
- `Research_Onion_Saunders_Application_Guide.md` (Full guide: 13 sections, 5,500+ words)
- `Research_Onion_Quick_Reference.md` (Cheat sheet: 1 page, 2,000 words)

**Purpose:**
- Establish coherent methodological design
- Connect philosophical assumptions to data collection techniques
- Five nested layers: Philosophy → Approach → Design → Methods → Techniques

**Your Five Layers:**

1. **Philosophy:** Critical Realism + Pragmatism
   - Epistemology: Corruption is objective but interpretation is socially-mediated
   - Ontology: Real phenomena + socially-constructed sources
   - Axiology: Transparency, accountability, democratic governance

2. **Approach:** Abductive (+ Inductive)
   - Observe fragmentation puzzle → Propose explanation → Test empirically

3. **Design:** Descriptive (+ Exploratory)
   - Characterize what corruption data sources exist

4. **Methods:** Mixed Methods (80% qualitative, 20% quantitative)
   - Document analysis + quality scoring + convergence metrics

5. **Techniques:** PRISMA + Bowen + Quality Assessment
   - Systematic source mapping + document analysis + triangulation

**When to Use:**
- Methodology chapter structure
- Demonstrating methodological coherence
- Responding to examiner questions about design choices
